1) STACK DE ESTILO
------------------
- Tailwind CSS v4 via plugin @tailwindcss/vite (sem tailwind.config.js clássico).
- Um único arquivo global: index.css com @import "tailwindcss" e bloco @theme.
- Fontes web carregadas no CSS (Google Fonts) + fallbacks de sistema.
- Opcional no projeto original: animações de rota com motion/react (Framer Motion
  API); não é obrigatório para o visual estático dos componentes.


2) FONTES
---------
Import (replicar no CSS global):
  https://fonts.googleapis.com/css2?family=Inter:wght@400;500;600;700;800;900
  &family=JetBrains+Mono:wght@400;500;600&display=swap

Família sans-serif (--font-sans):
  "SF Pro Text", "SF Pro Display", -apple-system, BlinkMacSystemFont, "Inter",
  "Segoe UI", Roboto, Helvetica, Arial, sans-serif

Família monoespaçada (--font-mono):
  "SF Mono", "SFMono-Regular", ui-monospace, "JetBrains Mono", "Roboto Mono",
  monospace

Uso típico:
  - Corpo: font-sans, antialiased.
  - Códigos, chips, labels técnicos: font-mono onde aplicável no App.

Marca (índigo / violeta):

Bordas:

Status / semântica (alinhados a utilitários Tailwind):

4) RAIO DE BORDA E “VIDRO”
--------------------------
- Cartões e blocos principais: rounded-2xl (glass, kpi, tbl-wrap externo).
- Botões e inputs: rounded-xl.
- Modal: rounded-3xl.
- Logo / avatares pequenos: rounded-xl ou rounded-lg conforme componente.
- Scrollbar thumb: rounded-full.

Efeito “glass” (cartão translúcido):
  .glass → bg-bg2/80 + border border-border + rounded-2xl + backdrop-blur-md +
           shadow-xl shadow-black/20

Hover em lista/cartões:
  .glass-hover → hover elevado, borda mais clara, translate-y leve, sombra com
  toque brand/5.


5) SOMBRAS E PROFUNDIDADE
-------------------------
- shadow-xl shadow-black/20 nos cartões glass.
- shadow-2xl em modal e toasts.
- shadow-lg shadow-brand/20 no ícone da logo e elementos de destaque marca.
- Topbar: bg-bg/60 backdrop-blur-xl (barra semi-transparente).


6) LAYOUT (ESTRUTURA DE PÁGINA — IDs usados no CSS)

8) MICROCOPY VISUAL (TIPOGRAFIA)
--------------------------------
- Títulos de seção em páginas: font-black ou font-bold com tracking-tight ou
  tracking-tighter onde quer impacto (ex.: logo).
- Metadados e navegação: text-[10px] ou [11px], uppercase, tracking-widest ou
  tracking-wider, cor text-text3.
- Corpo em listas/tabelas: text-sm, text-text2 nos td; ênfase com text-text ou
  font-bold.


9) SCROLLBAR (WebKit)
---------------------
Largura 1.5 (6px), track bg-bg2, thumb bg-bg4 rounded-full.


10) ANIMAÇÃO GLOBAL
-------------------
@keyframes slide-up: opacidade 0→1, translateY 8px→0, 0,25s ease.
Registrada como --animate-slide-up no @theme.


11) COMO APLICAR EM OUTRO PROJETO (CHECKLIST)
---------------------------------------------
[ ] Instalar Tailwind v4 + @tailwindcss/vite (ou equivalente que suporte @theme).
[ ] Copiar o bloco @theme (cores, fontes, keyframes) para o CSS global do projeto.
[ ] Copiar @layer base (html/body, scrollbar) e @layer components completo de
    index.css (ou extrair para tokens + componentes do seu design system).
[ ] Garantir import das fontes Inter + JetBrains Mono (ou substituir mantendo a
    escala de pesos 400–900 no sans e 400–600 no mono).
[ ] Aplicar no root: className/min-h-screen com fundo bg-bg e texto text-text.
[ ] Reproduzir grid: sidebar fixa 256px + main flex-1 com topbar + content com
    padding p-6.
[ ] Substituir botões/inputs nativos pelas classes .btn-*, .inp, .lbl onde couber.
[ ] motion/react: opcional; transições de página usam opacity + translateY leves
    (duration ~0,15–0,2s) no código React, alinhadas ao estilo “suave”.

Arquivo de referência no repositório:
  attivos/src/index.css (fonte única de verdade visual)
  attivos/index.html (lang pt-BR, viewport padrão)
  attivos/vite.config.ts (plugin tailwindcss())


12) OBSERVAÇÕES
---------------
- Ícones no App: lucide-react (tamanhos frequentes 12–18px em linhas compactas).
- Não depende de arquivo tailwind.config separado: tudo deriva de @theme no CSS.
- Para React sem Vite, adapte o equivalente PostCSS/plugin Tailwind 4 para gerar
  as mesmas utilities a partir do mesmo @theme.
